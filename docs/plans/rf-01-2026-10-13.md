## Slice (owned paths only)
`scripts/quality/text_ink.py` renders one text element through the existing `RealRenderer` (reused, hash-pinned faces, no fallback) and measures pixels with numpy.
1. `PINNED_FACES`: the seven brand-font SHA-256 values; any other bytes are rejected.
2. `measure_ink(...)`: render on a padded canvas (padding keeps transforms and fractional sizes), return ink bounds and pixel count in element coordinates.
3. `check_bounds(...)`: ink outside the element box (rotated box for rotation) is `overflow`.
4. `check_clip(...)`: padded ink falling outside the real canvas is `clipped`; the clipped render's ink count must equal the in-canvas padded count (otherwise the probe itself is inconsistent).
5. `shaping_notes(...)`: record unsupported shaping (missing glyph, complex-script codepoints, no GPOS `kern`, size truncation).

## Paired controls (written first, fail until implemented)
| behavior | failing case | valid control |
| --- | --- | --- |
| word wrapping | long word in narrow box -> overflow | same text, wide box -> clean |
| clipping | element straddling canvas edge -> clipped, lost ink > 0 | same element inside canvas -> clean |
| rotation | rotated element, ink checked in rotated frame | rotation 0 baseline |
| fractional size | 24.9 draws as 24: ink equals 24, differs from 25 | integer size baseline |
| kerning | "AV" ink width equals sum of advances (no kern applied), recorded | n/a (recorded limitation) |
| substitution | unpinned font bytes rejected | pinned face accepted |

## Limits
No Pillow wrapping helper as oracle. Complex scripts and untested official faces remain unqualified. No visual-quality or sample-pass claim.
