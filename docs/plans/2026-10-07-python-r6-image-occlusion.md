1. Defect (evidence JSON, L3 -> 728x90): source headline [90,620,900x220] and product [340,180,400x400] do not overlap; P4 no overlap; P5/P5b headline [0,10,725x33.5] overlaps product [350.7,12,26.7x26.7]. refit() treats only grouped boxes as obstacles, so ungrouped images are ignored.
2. RED control (tests_python/test_text_fit.py, fails on main): for every re-fit ungrouped text T and every ungrouped image I, if source aabb(T) and aabb(I) did not overlap, output aabb(T) and aabb(I) must not overlap (GAP not required). 3. Smallest fix: in refit(), add ungrouped images to the obstacle list per text. An image is an obstacle for text T only if source aabb(T) did not overlap it. _pack gets a per-unit exemption (indices of fixed rects to ignore); no other path changes.
4. Unchanged: grouped placement, rotation values, non-geometry fields, input immutability, FLOOR_PX=6, shrink ladder x0.9, GAP 2, no raise on schema-valid input. Uniform path (nothing below floor) untouched; L1/L2 JSON must stay cmp-identical to base.

6. Not in scope: ungrouped shapes as obstacles (shapes are plates/decoration, source overlap common); grouped label size; image z-order (an overlapping text may be on top of the image in z, I report geometry, not visual quality).
7. Evidence: docs/evidence/2026-10-07-r6/: genuine-renderer PNG + JSON before (main) and after (fix) for L3 and S3/S4, L1/L2 JSON sha before/after, per-text overlap table, mutants (obstacle off, exemption off, floor off).
