For each case, `jq` comparison of archived baseline and selected editable documents found identical ordered `id`, `type`, `role`, text, asset, color, font family/weight, and group membership records; group arrays matched too. This checks protected fields in the archived documents, not editability inside Adobe Express. Archived diagnostics reported zero geometry errors for each baseline and selected result. Warning counts changed from 3 to 0 for `after-dark`, 1 to 0 for `long-headline`, 0 to 0 for `grouped-details`, and 1 to 0 for `intentional-overlap`; these findings share logic with candidate selection and are not the visual verdict.

No selected output in this small set showed a new hard visual defect at the reviewed image size. The missing arrow deserves a font/rendering follow-up under #3, but changing the layout engine would not fix a glyph absent in the source render. This check does not establish performance on outside designs or Adobe's native document surface.
